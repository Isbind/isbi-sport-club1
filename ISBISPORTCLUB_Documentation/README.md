## 🌟 Vue d'ensemble
Ce fichier Excel est conçu pour gérer l'ensemble des opérations de votre salle de sport ISBISPORTCLUB, y compris la gestion des membres, des abonnements, des paiements et des présences.

## 💻 Installation
1. **Configuration requise** :
   - Microsoft Excel 2016 ou version ultérieure
   - Macros activées (pour les fonctionnalités avancées)

2. **Première ouverture** :
   - Cliquez sur "Activer le contenu" si une barre de sécurité jaune apparaît
   - Autorisez l'exécution des macros pour les fonctionnalités complètes

## 👥 Onglet Membres
### Ajout d'un nouveau membre :
1. Saisissez un ID unique
2. Remplissez les informations personnelles
3. Sélectionnez le statut dans la liste déroulante

### Fonctionnalités :
- Validation automatique des emails
- Mise en forme conditionnelle pour les champs obligatoires
- Filtres pour trier les membres par statut

## 💳 Onglet Abonnements
### Création d'un abonnement :
1. Sélectionnez le type d'abonnement dans la liste déroulante
2. La date de fin est calculée automatiquement
3. Le prix se met à jour selon le type d'abonnement

### Suivi :
- Les abonnements expirés sont mis en évidence
- Calcul automatique de la durée restante

## 💰 Onglet Paiements
### Enregistrement d'un paiement :
1. Sélectionnez la méthode de paiement
2. Le statut se met à jour automatiquement
3. Liens automatiques avec l'onglet Abonnements

### Rapports :
- Vue mensuelle des revenus
- Historique des paiements par membre

## 🏋️ Onglet Présences
### Enregistrement :
1. Scan du badge ou saisie manuelle de l'ID
2. L'heure d'arrivée est enregistrée automatiquement
3. Calcul automatique de la durée de la séance

### Statistiques :
- Fréquentation par créneau horaire
- Taux de fidélisation

## 📊 Tableau de Bord
### Indicateurs clés :
- Nombre de membres actifs
- Taux de renouvellement
- Chiffre d'affaires mensuel
- Taux d'occupation des cours

## 💡 Conseils d'Utilisation
### Raccourcis clavier :
- `Ctrl + N` : Nouvelle entrée
- `Ctrl + F` : Rechercher un membre
- `Ctrl + P` : Imprimer la vue actuelle

### Bonnes pratiques :
- Mettre à jour régulièrement les statuts
- Sauvegarder le fichier quotidiennement
- Exporter les données mensuellement pour archivage

## 🔧 Maintenance
### Tâches récurrentes :
1. Vérification quotidienne des présences
2. Mise à jour hebdomadaire des statuts
3. Sauvegarde mensuelle des données

### Dépannage :
- Problèmes d'affichage : Vérifier la résolution d'écran
- Formules non mises à jour : Appuyer sur F9
- Fichier lent : Supprimer les lignes vides inutiles
